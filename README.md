# ShopEase Dynamic Analytical Dashboard — Group 001_033_040

FBDA group project · Abhinav Chhabra (075001) · Vidit Garg (075033) · Sarthak Keshaw Nigam (075040)

* Data: https://www.kaggle.com/datasets/mernahabib/shopease-raw-orders-dataset
* 2,500 random records, seed = 1033040 (Group ID without underscores)

## Run locally
```
pip install -r requirements.txt
streamlit run app.py
```

## Deploy (permanent live link)
1. Upload the files in this folder to a public GitHub repo (app.py, shopease_core.py, requirements.txt,
   shopease_raw_orders.csv, .streamlit/config.toml).
2. Go to share.streamlit.io → Create app → select the repo → main file `app.py` → Deploy.
